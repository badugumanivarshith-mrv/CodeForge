# Personal Digital Brain Documentation

## 1. Overview

The Personal Digital Brain provides a unified, continuous cognitive profile that captures every interaction, learning milestone, architectural preference, and problem-solving pattern for each user.

## 2. Capabilities

### 2.1 Unified Memory Indexing
Integrates working scratchpads, episodic milestones, and semantic concepts into a single coherent graph with automated Ebbinghaus consolidation passes.

### 2.2 Interactive Reasoning Explainer
Provides glass-box transparency for any decision, recommendation, or autonomous action:
- **Premises Used**: Specific user preferences and active memory entries referenced.
- **Axioms Applied**: Foundational logical, safety, and architectural constraints.
- **Verifiable Proofs**: Cryptographic zero-knowledge proof hashes validating trace integrity.

### 2.3 Dominant Thinking Patterns
Automatically extracts recurring problem-solving archetypes, such as:
- *First-Principles Systems Decomposition*
- *Dialectic Synthesis & Adversarial Invariant Checking*
- *Recursive Sub-Goal Formulation*
