# Multi-Agent Collaborative Councils Documentation

## 1. Five Specialized Councils

CodeForge V2 orchestrates five specialized Agent Councils:

1. **High-Throughput Engineering Council**:
   - Focus: Scalability, compiler pipelines, distributed CRDTs, zero-trust memory enclaves.
2. **Autonomous Research & Foundations Council**:
   - Focus: Neuro-symbolic logic proofs, academic literature synthesis, model benchmarks.
3. **Executive Talent & Career Strategy Council**:
   - Focus: Career trajectories, salary intelligence, leadership and executive mentorship.
4. **Socratic Curriculum & Pedagogy Council**:
   - Focus: Mastery learning, spaced repetition intervals, adaptive diagnostic rubrics.
5. **Cognitive Superintelligence Executive Council**:
   - Focus: Planetary compute grid balancing, multi-horizon strategic roadmaps, self-improvement mandates.

## 2. Dialectic Debate & Consensus Protocol
- **Perspective Gathering**: Multi-agent perspectives submitted with confidence weights.
- **Contradiction Detection**: Automatic lexical and logical contradiction identification.
- **Expert Voting**: Weighted aye/nay votes with mandatory rationale logging.
- **Consensus Ratification**: Converged synthesis ratified at $\ge 60\%$ supermajority.
