# 03-Digital Laboratories & Simulation Orchestrator

This document details virtual HPC compute provisioning and continuous experiment execution.

## Simulation Pipeline

1. **Virtual Lab Clusters**:
   - Computes capacity limits in Teraflops.
   - Monitors mounted datasets and active simulations.
2. **Simulation Sweeps**:
   - Executes numerical solvers.
   - Computes logs, CPU duration, and reproducibility index.
